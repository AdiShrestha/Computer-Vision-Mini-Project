# Current license and data-attribution status

The root LICENSE is proprietary and remains unchanged. Earlier documentation claiming an Apache or equivalent open research release was incorrect and is withdrawn. This notice grants no new rights and does not replace the root terms. A future research-code/data release needs an actual owner decision and separate review of upstream restrictions.

Provider attribution must correspond to products actually admitted and used. Current catalogue records and unverified derived outputs do not establish use of all listed sensors, datasets or years. No present claim that the complete study uses a particular inventory, DEM or reanalysis product is inferred from an intended feature list.

For a future release, record each actual dataset/provider/version, retrieval or redistribution conditions, required attribution, primary citation and affected artifacts. Candidate sources include Copernicus Sentinel, ERA5 regional reanalysis, lake inventories, optional Randolph Glacier Inventory/GLIMS glacier relations and actual elevation products. A glacier inventory does not authenticate a lake outline. An intermediary weather API must be named alongside the underlying model and its own terms.

If redistribution is restricted, provide an allowed retrieval recipe and inspectable metadata. Public availability alone does not grant reuse rights. Source-specific legal notices and attribution text must be checked against the actual selected product before publication; earlier unsourced blanket licensing statements are not retained as release assurances.

The project has no established operational life-safety warning capability. Research limits and data-use conditions must remain visible in any future release.
