# Local integrity maintenance over Software Factory v3.3.0

Date: 2026-10-01. State: implemented local corrections with offline regression evidence; independent architect maintenance review pending. This is not an upstream factory release or a completed Sentinel-GL adapter. `VERSION = '3.3.0'` retains existing plan compatibility. Frozen `engine_sha256` binds the changed active installation, including code, policy and tests; old epochs must not be rewritten or rebound to new bytes.

The user authorized correction of mathematical and research-integrity defects. These changes repair false measurements and false assurance, preserving observational, scientific and review blockers. They do not waive scientific requirements to improve speed or results.

| Area | Correction | Meaning and limits |
|---|---|---|
| Signatures | Require `cryptography` Ed25519; remove HMAC secret-as-public-key fallback; verify using public key only; reject missing/malformed/legacy key schemes | Offline verification no longer needs a signing secret. Existing HMAC keypairs require explicit migration/rotation; they are never overwritten automatically. Local trust still depends on the independently trusted public key and same-user filesystem. |
| Run bindings | Audit verifies signature and exact typed identity, nonce, epoch, project, inputs, outputs, resolved launch, lock, runtime metadata, exit status and times | A valid signature for a different run fails. Output rehashing cannot repair a stale signed output root. Runtime metadata is recorded from the local supervisor, not a protected measured boot or worker attestation. |
| Assurance | A result path does not promote assurance; all accepted runs need verified receipts for local attestation and research certification | The local execution tier cannot exceed `SUPERVISOR_ATTESTED`. No same-user runner is claimed to provide sealed evaluation. Domain/scientific checks and actual review remain separate. |
| Telemetry | New `engine/telemetry.py` uses per-child `wait4` resource accounting where available; wall time is separate; unsupported values are null/reason | Darwin RSS uses bytes, Linux RSS uses KiB converted to bytes. CPU is user+system CPU for the waited child. RSS is OS accounting, not total unified/GPU memory, sampled device allocation, or system peak. Descendant/process accounting follows platform semantics. |
| Schema | Receipt version 2; epochs and class counts must be integers; p-values finite in [0,1]; confidence bounds ordered; finite-range conversion errors explicit | Counts are not fractional observations. Receipt v1 epochs are preserved; the new audit requires prospective re-execution rather than relabeling old telemetry. |
| Typed launch | Contained, nonsymlink entrypoints; known arguments with exact bindings; audit argv resolved by the same authoritative contract resolver | The positional ABI is sorted argument keys. It is tested explicitly. The only installed typed runtime still uses `-S`, so the scientific package runtime remains unfinished. |
| Enforcement | Use a finite inherited OS-variable allowlist, removing arbitrary supervisor/provider/other credential variables from worker environment; fail before launching a typed `network: disabled` contract when denial cannot be enforced; do not swallow limit failures | This is truthful refusal, not an implemented network sandbox. Same-user workers may still reach files available to that user. Platform resource limits have platform semantics, not a total GPU/unified-memory cap. |
| Attempts | Retain failed runs; require canonical consecutive attempt numbering in run and audit | Deleting an earlier failure leaves a detectable gap. Deleting trailing/all history cannot be proven from mutable local state alone. A protected external witness/append-only record is needed for the stronger claim. |
| Statistics | Sign-flip tails compare exact integer-scaled binary64 differences, without an absolute tolerance or rounded-mean ties; differences and settings checked | Rescaling a tiny nonzero contrast no longer changes its p-value to one. Conditional seed inference remains conditional on a fixed test corpus, not event-population inference. |
| Plausibility | Remove universal 0.5 chance thresholds for precision/recall/F1/accuracy; permit an explicitly identified reference; exact negative verdicts are not “all supported” | AUROC's no-information reference remains 0.5 for its defined two-class ranking task. A `chance_reference` value is a diagnostic input; scientific baseline claims still need traceable independent calculation. |
| Checkpoint selection | Early stopping significance threshold controls patience; chosen checkpoint uses minimum observed validation loss | This agrees with the corrected core. Budget exhaustion still needs a prospectively justified scientific disposition; flat loss alone is not proof of useful learning. |
| Independent bundle verification | Strict duplicate/nonfinite JSON handling; trusted Ed25519 only; real nested receipts supported; bind record fields and complete included outputs; disclose declared vs verified assurance | Unkeyed byte verification cannot establish execution. Signed bare payloads prove signature only. The independent verifier does not independently validate provider identity, cohort support, model training, or scientific inference. |
