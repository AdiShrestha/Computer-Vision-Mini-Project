# InSAR feasibility: current evidence boundary

**No empirical SLC/InSAR feasibility result is established.** The existing dossier was produced from assumed storage sizes, selected terrain angles and a parametrized coherence-decay calculation. These are constructed planning scenarios, not processed Sentinel-1 SLC pairs, measured terrain geometry or observed coherence.

Earlier conclusions that monsoon phase processing is infeasible, that a particular pre-event coherence collapse was measured, or that GRD amplitude guarantees uninterrupted usable coverage are withdrawn. Hypothetical calculations cannot determine a scientific sensor exclusion or support a negative observational result.

A genuine pilot must identify compatible SLC pairs, orbit/DEM/ROI inputs, processing versions, coregistration, interferograms, coherence and quality masks, reference/atmospheric/geometry uncertainty and actual output hashes. Conclusions are limited to the tested geometry, period, workflow and support and require specialist review.

The existing scenario JSON is excluded from empirical claims pending proper origin separation. Any retained analytical examples must state their assumed parameters and scope. No measured deformation, coherence, phase-unwrapping success or failure is claimed here.
