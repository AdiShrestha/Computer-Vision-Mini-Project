# Data availability

* **Derived data deposit** (CC BY 4.0): built by `make deposit` as `release/sentinel_gl_data_v1.zip` with a SHA-256 manifest of every file. It contains the 141 Sentinel-2 ROI arrays and their receipts, STAC items and native metadata, the retained 2023 parent arrays, the inventory zones, the training run manifest and all checkpoints, predictions, reconstruction errors, positive-control rows and replay arrays. Zenodo DOI: 10.5281/zenodo.24338676.
* **Code** (MIT): this repository, archived as `release/sentinel_gl_code_v1.zip` (git archive of the release commit); Zenodo DOI: 10.5281/zenodo.24339345.
* **Source data**: Sentinel-2 Collection-1 Level-2A products are openly available from the Earth Search STAC API (collection `sentinel-2-c1-l2a`); exact item identifiers are in the corpus manifest. The Hi-MAG lake inventory is available at doi:10.5281/zenodo.4275164.

Contains modified Copernicus Sentinel data [2018–2023].
