# Diagnostic figures

These quarantined figures describe retained development diagnostics; they are not research-admitted evidence and cannot establish event-detection, warning, water-area or comparative-performance claims. The observation plot contains four site-sensor group records derived from three provider products: both SAR site ROIs share one Sentinel-1 product, and the two optical groups use distinct Sentinel-2 products. Group counts are not independent acquisition or sampling-unit counts. Historical provider availability is unknown for all groups.

Raw calibrated sigma0 is an ellipsoid-only diagnostic with unknown Sentinel-1 source timezone, no terrain correction, no lake ROI and no quantified cross-sensor registration uncertainty. Optical distributions describe spatial pixel spread, not measurement uncertainty. Figures 6–7 show actual selected-checkpoint attention computations over sparse pooled source tokens, averaged over layers and heads within each seed/sample; they do not show causality, feature importance, event detection or a full 2023 sequence. Unsupported event-performance plots remain listed with explicit unavailable statuses in `manifest.json`.
